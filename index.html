◆Características

Ingeniería que se nota.

Cada decisión técnica de Lumiz persigue lo mismo: wallpapers nativos, ligeros y sin comprometer tu privacidad. Sin Electron, sin telemetría, sin promesas vacías.

01

Direct3D 11 nativo

Renderizado por hardware detrás de los iconos del escritorio. Latencia set_wallpaper → primer Present ≤ 1500ms p95 (hoy ~120-200ms). Sin capas de Electron.

02

Arquitectura de doble proceso

UI host (WinUI 3) y Engine (D3D11) en procesos separados vía Named Pipes con handshake ECDH P-256 + HMAC-SHA256. Un crash de UI no mata tu wallpaper.

03

Native AOT

Compilación Ahead-Of-Time en .NET 8: arranque instantáneo, sin JIT, menor superficie de ataque. Working Set del Engine ≤ 80MB tras 10min.

04

Cero telemetría

Ningún plan recoge métricas. DB local con SQLCipher + AES-256-GCM. 52/52 chequeos de seguridad en verde. Tu escritorio, tu privacidad.

05

Compatible con Lively

La Fase D importa wallpapers .zip de Lively (LivelyInfo.json), de Workshop de Wallpaper Engine, y añade picture slideshow, streams en vivo y web wallpapers vía WebView2.

06

Cloud opcional (Max)

Sync entre dispositivos + galería curada vía Supabase + Cloudflare R2. Solo para Max (29,99$ lifetime). Free sigue siendo 100% local y gratis.

◆Cómo funciona

Tres pasos, cero fricción.

Sin cuentas, sin configuración imposible. Lumiz está diseñado para que tu wallpaper esté vivo en segundos.

01

Importa tu wallpaper

Arrastra una imagen, GIF o vídeo a la library — o pega una URL de stream. Lumiz lo importa a %LOCALAPPDATA%\Lumiz\Library\ en menos de 2 segundos.

drag-drop · URL · bulk import

02

Configura el comportamiento

Elije monitor, pausa en fullscreen o al desconectar el cargador, ajusta el audio. Cada wallpaper guarda sus propias propiedades.

per-display · pause rules · audio

03

Lumiz lo renderiza tras tus iconos

El proceso Engine abre una ventana Direct3D 11 detrás de Progman/WorkerW. Tu escritorio sigue siendo interactivo, tu wallpaper vive.

D3D11 · Progman/WorkerW · AOT

◆Arquitectura

Dos procesos, cero compromisos.

Lumiz separa la interfaz de usuario y el motor de renderizado en dos procesos independientes. UI y Engine se hablan por Named Pipes con handshake ECDH P-256 + HMAC-SHA256, de modo que un cuelgue de la UI nunca mata tu wallpaper.

◆Seguridad

Privacidad por diseño.

Lumiz no recoge telemetría en ningún plan. La base de datos local se cifra con SQLCipher AES-256-GCM y la comunicación entre procesos se protege con un handshake ECDH P-256 + HMAC-SHA256. Tu escritorio, tus datos, tu privacidad.

01

Cero telemetría

Ningún plan recoge métricas, analíticas ni eventos. Sin endpoints, sin trackers, sin excepciones.

SQLCipher AES-256-GCM

La base de datos local se cifra en reposo con AES-256-GCM. Las claves nunca salen del dispositivo.

ECDH P-256 · HMAC-SHA256 · Named Pipes

Lumiz es nativo de Windows y renderiza sobre Direct3D 11. Estos son los requisitos para ejecutarlo hoy y para desarrollar sobre él.
